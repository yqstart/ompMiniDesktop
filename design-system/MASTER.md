# 设计系统

> 本站唯一视觉 / 交互真相。改 UI 前先读；token 与类名的运行时源在 `src/index.css`（本文与它冲突时以「先改文档再改实现」为准）。
> 母版：`docs/benchmark-codex-desktop.md`（Codex 设计语言合约）＋ `docs/benchmark-zcode-desktop.md`。方向：**聊天唯一形态**（v1 形态收敛后的形态）。
> 现行实现自 V42 起已按「中性近黑 / 近白外壳」对齐两家产品；本文把该口径补全为完整的语义体系。**聊天对标（v2）与设置重构（v3）的落地项均已按下文标注实施**（三栏布局、语义 token、输入卡、消息流摘要行、设置重构）。

## 1. 设计原则

1. **工作台优先**：没有落地页、hero、营销构图；第一屏就是可用工作面。
2. **密度高而不挤**：短标签、紧凑行、可见结构；空白用于分隔工作区，不造戏剧性。
3. **安静**：冷静、哑光、低对比；面板与行以分隔线和底色差组织，**不做嵌套卡片**。
4. **克制**：单一 accent，只用于活动态、焦点、选中项与重要状态；状态色（成功 / 警告 / 危险 / diff）只表达状态，不做装饰。
5. **快**：动效短而实用；只动 color / opacity / transform，不动布局尺寸。

## 2. 设计 token

### 2.1 颜色（`src/index.css` 为源，深浅两套）

| Token | 角色 | 浅色 | 深色 |
|---|---|---|---|
| `--background` | 工作面 | `#f9f9f9` | `#181818` |
| `--sidebar` | 侧栏（比工作面更深 / 更暗一档） | `#f3f3f3` | `#121212` |
| `--surface` | 卡片 / 面板 | `#ffffff` | `#212121` |
| `--elevated` | 浮层 / 弹窗 | `#ffffff` | `#303030` |
| `--foreground` / `--muted` / `--faint` | 文本三级：主 / 次 / 弱 | `#1a1c1f` / `#5d5d5d` / `#767676` | `#e6e6e6` / `#a8a8a8` / `#8f8f8f` |
| `--border` / `--border-soft` | 边框两档（黑色 / 白色透明度，不用实色灰） | `rgb(13 13 13 / 12%)` / `7%` | `rgb(255 255 255 / 10%)` / `6%` |
| `--accent` | 唯一强调色（OpenAI 蓝）：链接、焦点环、选中指示、进行中状态 | `#0169cc` | `#339cff` |
| `--primary` | 主动作实心钮（近黑 / 纯白） | `#1a1c1f` | `#ffffff` |
| `--danger` / `--warn` / `--ok` | 状态色 | `#dc2626` / `#b45309` / `#047857` | `#f87171` / `#fbbf24` / `#34d399` |
| `--hover` / `--active` | 行悬停 / 选中填充（透明度叠加） | `5%` / `9%` | `7%` / `11%` |
| `--code` | 代码块底 | `#f0f0f0` | `#101010` |

**规则**：不引入新的强调色、渐变、霓虹与纯黑；新状态一律 `color-mix()` 从既有 token 派生。浅色下主按钮 = 近黑实心白字，深色下 = 纯白实心深字（`--primary`）；accent 按钮仅用于次要强调动作（如「重启生效」），不做大面积实心。

### 2.2 字体

- `--font-sans`：系统 UI 栈（含中文字族）——界面主体。
- `--font-mono`：`JetBrains Mono / SF Mono / Menlo / monospace`——代码、路径、键名、时间戳、token 数、快捷键之外的数字元数据；配 `font-variant-numeric: tabular-nums`（`.font-mono` 已带）。
- **与 Codex 的偏离（有意）**：Codex 是 mono-forward 栈，本站面向中文会话，正文用 sans 保证中文可读性；「等宽感」通过 mono 用在所有**元数据与代码**来表达。
- 字级（沿用 Tailwind 档）：正文 `text-sm`(14) 为主；次要元数据 `text-xs`(12)；面板标题 / 区块标题用 `text-xs font-medium` + `muted`，**不用页面级大标题排版**（设置页头例外，用 `text-base`）。
- 层级优先用字重与颜色（foreground → muted → faint），再考虑放大；标题罕见。
- `kbd` 一律 `--font-sans`（元素规则已钉，组件不许再挂 mono）。
- **标题不显示标题卡前缀**（2026-10-14 起，2026-10-15 扩到短码）：omp 18.8.7+ 的标题卡（`title.icons` 默认 `nf+emoji`）会把标题写成 `${icon} ${code}: ${title}`（实测 `󰜘 COMMIT: 提交推送后仍有修改标识`）——图标是私有区码位，壳里没有覆盖私有区的字体，WebKit 会回退成 Apple Symbols 的杂物字形（实测 U+F084D 画成 6 根横条）；图标后面的大写短码（`COMMIT:` 这类分类码）在终端里是卡片、在壳里只是噪音。显示层统一去掉标题**开头**这整段前缀（图标 + 短码；`lib/sessionTitle.ts` 的 `sessionTitleForDisplay`，侧栏 / 删除确认 / 顶栏 / 归档页 / 设置搜索 / **改名输入框回显**同口径），数据不动（jsonl 标题、导出仍带前缀）；没有图标的裸 `HGT: ` 不是卡、不剥。改名输入框的提交口径：Enter 或点输入框外保存（改过才写），Esc 取消。不给私有区装字体：标题里的图标只是数据噪音，不是设计语言的一部分。
- 终端图标字体（OMP Nerd Icons）与终端形态一同在 v1 退场：字体资产、`@font-face` 与 `--font-mono` 里的挂载都已移除，不要再引回。

### 2.3 圆角 / 阴影 / 动效

- 圆角：`--radius-sm` 5 / `md` 8 / `lg` 12 / `xl` 16 / `2xl` 20。行与图标钮用 sm–md；输入卡 / 大面板用 xl；弹窗 xl–2xl。桌面主区外沿 8–16px（V42 口径）。
- 阴影只用两档：`--shadow-pop`（浮层）/ `--shadow-dialog`（模态）；深色下靠 `--elevated` 亮度差与边框定型。
- 动效：120–200ms 区间；只动 color / opacity / transform；按下位移 ≤1px；`prefers-reduced-motion` 下全部收敛（流式呼吸光标等已有全局规则，保持）。

### 2.4 语义层 token（v2 已落地，源在 `src/index.css`）

跨组件布局决策进语义变量或组件内局部（禁止散落魔数）：

| 变量 | 用途 |
|---|---|
| `--h-chrome` | 顶栏高度（44px 档：中列 TopBar / 右栏面板头；左栏顶行是局部 32px，见 §3） |
| `--h-row` / `--h-row-lg` | 列表行高（紧凑行 / 大行） |
| `--w-sidebar` | 左栏宽度（现 292–480 拖宽，默认 292） |
| `--w-panel` | 右栏工作台**默认**宽度（V42；实际宽度由 `store.workbenchWidth` 驱动，左缘可拖 260–640） |
| `--measure-content` | 中列内容测量宽（正文 / 输入卡 / 目标条 / 查找条 / 归档提示共用，`min(88rem, 85%)`；两侧各留 7.5%，超宽屏才封顶居中） |
| `--w-settings-nav` | 设置左导航宽（176px 文字档 / 44px 图标档） |
| `--w-menu-sm` / `--w-menu-md` | 菜单宽两档 |
| `--z-*` | 命名层级（见 §5） |

## 3. 布局（聊天唯一形态）

```
┌──────────┬────────────────────────────┬────────────┐
│  左栏     │  中列                       │  右栏工作台 │
│  会话树   │  ┌ 标题栏（会话名 + 工具组）│  文件 / 终端 │
│  项目分组 │  ├ 消息流（thread）         │  （双页签） │
│  搜索     │  │   用户右泡 / 助手通栏    │            │
│  底部设置 │  └ Composer（输入卡）       │            │
└──────────┴────────────────────────────┴────────────┘
```

- **左栏**：宽 292（可拖 292–480）；顶行（32px，拖窗区 + 版本 chip，与 macOS 红绿灯同一行、`pl-72px` 避让；**omp 缺失时版本处换成「安装 omp」chip**——图标 + 短文案，点击打开安装弹窗，安装中转圈、失败带 warn 点，与版本 chip 同高同色板）；常驻命令行（只有新建会话——原「快速切换」⌘K 命令中心已按用户口径删除，2026-10-19）；会话树；底栏（设置 / 语言 / 皮肤）。窄窗（<768px）收抽屉。
- **中列**：标题栏（**标题靠左**，紧跟一枚「导出会话」图标钮，右端只剩右栏工作台开关；2026-10-19 用户口径——原左侧 `···` 会话菜单整条退场，重命名回点标题、归档回左栏行操作、会话统计走卡底统计条。**整条标题栏都是窗口拖拽区**（`data-tauri-drag-region="deep"`，2026-10-20 用户实测修复）：裸属性只认**直接命中 header** 的 mousedown，而内容全在两层 flex 容器里——按在标题 / 空白上都拖不动窗口；`deep` 让子树里任意点击都算拖拽，交互件（标题按钮 / 导出 / 工作台开关 / 改名输入框）不带属性、拖拽脚本按 clickable 元素短路，点击语义不变；空态标题是 disabled 按钮，禁用态挂 `pointer-events-none` 把这一片让回标题栏）→ 消息流（`.thread-scroll`，独立滚动，见 §4.5）→ Composer。内容列宽 = 中列 85%（`--measure-content`，两侧各留 7.5%）——消息流正文 / 输入卡 / 查找条 / 目标行**同宽、左缘对齐**（中列 > 1656px 才封顶 88rem）；容器**不许再挂水平内边距**（`85%` 相对各自包含块，挂上基准就不同、看着错位）。消息流底部另有**任务清单浮卡**（§4.8；有清单时才在，挂在 Thread 相对定位外壳内、不随滚动移动，宽度与正文列同档）。
- **右栏工作台**（V42 已落地）：始终停靠为主区第三栏（打开 = 布局变三栏，会话列让位、不遮盖）；可整栏开关（`store.workbenchOpen`，⌘⇧G，**每次启动都收起**、不恢复上次展开态）；内部两个页签（**文件**目录树 / **终端**），规范见 §4.9。宽度可拖（`store.workbenchWidth`，260–640，默认 320，持久化）。
- 桌面主区外沿圆角 8–16px；窗口级永不滚动（`#root` 锁死），滚动只发生在各列内部。

## 4. 组件规范

### 4.1 按钮（按角色，禁止手搓悬浮态）

| 角色 | 形态 | 例子 |
|---|---|---|
| 图标钮 | `size-6/7` 裸图标 + `hover:bg-hover`、圆角 sm；激活 / 选中态 `bg-active` + 前景升档 | 行级操作、工具组、关闭 |
| 命令钮 | 图标 + 文字，紧凑（`h-7` 档） | 「生成提交信息」「安装」 |
| 主按钮 | `--primary` 实心（浅色近黑 / 深色纯白） | 发送、提交、确认 |
| 次按钮 | 边框 + surface 底 | 取消、次要动作 |
| 危险按钮 | `--danger` 文本或实心（破坏性确认） | 删除会话 / 项目 |

- 行内按钮组用**互斥槽**口径（V43）：按钮组流内常驻占位（opacity 切换、槽宽零位移、键盘可 Tab），信息（时间 / 计数）为 `absolute right-0` 覆盖层，悬浮 / 聚焦整行时互换；具名 group 防「hover 子行串亮父行」。

### 4.2 行（列表行通用形态）

- 行 = 无图标盒的裸图标 + 文本 + 行尾状态；选中 = 中性填充（`--active`）+ 前景升档，**不做彩色竖条、不做图标盒**（V42 口径）。
- **会话行 = 行首状态点 + 标题 + 行尾时间**（2026-10-19，形态照 DeepSeek Harness 的会话行，落地在 `components/sidebar/SessionStatusDot.tsx`）：状态点占固定 16px 槽（空闲留白，标题列不错行、整行仍可点），四档**优先级唯一**——待处理（橙点，等审批 / 等回答）> 运行中（中性灰转圈环，14px：淡轨道 + 一段转动的弧）> 已完成未查看（绿点，视觉 6px）> 空闲（不显示）。**待处理档行尾把相对时间换成「待处理」标签**（完整时间进悬停 `title`）。色彩只给「要你关注」的档位（`--warn` / `--ok`），进行中保持中性 `--faint`（**不再用 accent**）；状态标只此一处，行尾不再重复转圈 / 对齐图标。
- 行高按角色：菜单行（28px 档）/ 列表行（30–32px 档）/ 设置行（min-h 44px 档，容纳描述）。
- 组头（项目 / 分组）：`text-xs` + `muted` + 计数；点击 = 选中 + 折叠；无独立折叠箭头。**启动时的默认开合（2026-10-19 用户口径）**：app 打开时只展开第一个顶层分组（有工作区 = 第一个工作区段；平铺 = 第一个项目块），其余收着；上次关闭时选中的会话所在的那一个优先展开（`lib/lastSession.ts` 的同一份记录驱动启动恢复）。开合受控、默认值随数据派生（不写 state），用户第一次点击后随点击走，不做持久化；工作区段内的项目块不占这套开合（展开了工作区，里面的项目就该看得见）。
- 项目头的 git 徽章（2026-10-19 修订）：脏点 / **待推送**（`BranchUp` + 数字，可点推送）/ **落后**（`Download` 下载图标 + 数字，**可点直接拉取**）/ 上游缺失（`LinkOff`）/ 任务态（转圈 / 失败感叹号）。落后徽章原来用 `BranchDown`（视觉上像收件箱）且只读，现在拉取态区分三档：**拉取中** = 转圈、禁用；**失败** = `AlertTriangle` + 危险色（悬停给 git 原文，点击重试）；**冲突** = `AlertTriangle` + 危险色，点击打开冲突清单（逐个用系统默认编辑器打开 + 继续合并 / 放弃合并）。壳里不解决冲突。

### 4.3 Composer（聊天输入卡，v2 已落地）

- 大圆角卡（radius xl），悬浮于中列底部；**宽度 = 中列 85%**（`--measure-content`，与消息流正文 / 查找条同档、左缘对齐；外层不挂水平内边距，见 §3）。**卡上顶行在卡片外部**（2026-10-20 用户口径）：项目 / 分支选择器 + 提交键（V42 起提交唯一入口）紧贴卡片上方、与卡片同宽左缘对齐，**不再是卡片的一部分**；卡片内部只剩两层——输入区（`DraftEditor`：Lexical 草稿编辑器、内容自适应、动态 placeholder）→ **卡底工具行**（左：`+`、执行模式；右：压缩行动点（≥80% 才露面）、Fast 服务档位（**只有一个闪电图标**；点击开 / 关 priority，开启变黄）、模型名 ▾、思考档 ▾（2026-10-14 与模型拆成两个独立选择器）、发送 / 停止）。**`@` / `/` 补全浮层也在卡片外部**（2026-10-20）：卡片上方的独立块（与卡片同宽、`mb-1.5`），不再塞进卡片内部把输入区往下推。**卡底统计条也在卡片外部**（2026-10-20，§4.10）：卡片下方独立一行（同宽、`mt-1.5`），不在卡框内。
  - **输入区 = Lexical 草稿编辑器**（2026-10-17，形态照 DeepSeek Harness 的 composer）：`@引用` 是**原子装饰节点**（`ReferenceChipNode`）——`14px` 类型图标 + 短标签（`@components/`、`@FileTree.tsx`），`--accent` 文字、无边框、与正文同基线（`px-1`、radius sm），hover 一层 `accent/10`；方向键一步跨过、Backspace 整块删除，点开可看完整路径（`title`）。**草稿恒定一个段落**，换行由 LineBreakNode 承载（Enter 发送 / Shift+Enter 软换行），因此编辑器全文就是 prompt 文本（引用序列化成真路径）。字体与排版与旧 textarea 一致：`text-sm leading-6`、`px-3.5 pt-3 pb-1`，高度随内容长，`max-h-44` 后内部滚动。占位符是编辑器内的绝对定位 `text-faint` 行（`top-3 left-3.5`）。
  - **`@` 补全里两种动作**：**文件 = 芯片**（原子、带类型图标、尾随空格收口）；**目录 = 下钻**——选中后写的是**路径文本** `@dist/`（光标停在其后），浮层立刻接着列这一层，想引用整个目录就直接发送这段文本。目录**不做芯片**（原子节点会挡住后续输入，用户实测「进不了文件夹」）。
  - **`@` 浮层顶部的「工作区文件」入口**（2026-10-20）：刚打出 `@`（token 为空）时，候选列表最上面多一行**工作区文件**（`FolderFiles` 图标 + 标题 + 右侧说明「从其他成员项目引用」），与路径候选之间一条 `--border-soft` 细线分隔——这一行是**打开 ⌘⇧P 跨项目引用浮层**的入口，不是路径候选；**默认高亮仍落第一条路径**（打 `@` 的主诉求是引用文件），↑ 一下才到入口，↑↓ / Tab / Enter 与路径行同一套键盘。非空 token（`@baselin`）不显示入口。**入口只对工作区成员出现**（2026-10-22 用户口径）：当前项目没进入工作区（未分组）/ 工作区里没有其他成员项目时不出现——没有可引用的范围，就不给这条动作。
  - **`+` / `/` 共用面板**（`SlashMenu`，2026-10-20 用户口径）：`+` 按钮与 `/` 打开同一个浮层——「操作」组（文件 / 工作区文件 / 压缩，行高与技能行同）+「技能」组（当前会话命令面的 `skill:<名>`，`Sparkles` + 名称 + 描述截断）；**omp 命令不再列出**（手打 `/xxx` 仍走 `run_slash`）。`+` 打开时列全部技能，`/` 打开时按输入过滤；**Esc / 点面板外关闭**（`useOutsideDismiss`：不抢编辑器焦点，触发按钮算「里面」；`@` 补全同口径、点编辑器里不算外部）；**目标 / 计划不在面板里**（工具行常驻按钮）。**「工作区文件」整行只在当前项目处于多成员工作区时出现**（2026-10-22 用户口径，`lib/workspaceFiles` 的 `hasWorkspaceRefs`）：未分组 / 单成员工作区不摆这条动作（不是禁用——没有可引用的范围），文件 / 压缩照常。
  - 引用**不再单独排一行芯片**（2026-10-17 用户口径）：标签已经融入正文，完整路径给在**输入框悬停提示**里（逐行 `@标签 → 真路径`）；只有解析不到的引用才在输入卡上方留一行 warn 提示。

### 4.4 消息流

- **宽度**：正文列 = 中列 85%（`--measure-content`，两侧各留 7.5%，中列 > 1656px 才封顶 88rem）——小窗口下正文不贴边、长行读数收敛；输入卡 / 查找条 / 目标条同一档，左缘对齐。
- 用户消息：右侧窄灰泡（`--hover` 级填充、圆角 lg、宽度 ≤72%）；助手：通栏正文。
- 摘要式折叠行（v2 已落地，`lib/threadLayout.ts` 派生）：
  - **命令批**：相邻 ≥2 条 bash 折叠为「运行了 N 条命令」，展开逐条原样（复用工具行）；
  - **编辑卡**：相邻 ≥2 条带行数增量的写 / 改折叠为「编辑了 N 个文件」，文件行常显、点击开对应 diff；
  - **任务清单批**：相邻 ≥2 条 `todo` 调用折叠为「更新了 N 次任务清单」（清单的当前状态看消息列底部浮卡 §4.8，这些行只留痕迹），展开逐条原样；
  - **轮时长行**：每轮末尾「用时 …」，展开显示起止本地时刻；没有可信时间戳的轮次不产这一行。
- 摘要行的数字用状态色（added = ok 档绿、removed = danger 档红，**只染数字与标记，不染整卡**）；单条工具行维持原样（不做「1 条命令」的假聚合）。
- 工具行：运行中 = 转圈 + 命令摘要（单行）；完成 = 折叠行。展开面板用分隔线分区，不做嵌套卡。
- 子代理生命周期 = 紧凑行（`Sparkles` 图标 + 文本），不画分隔线；其余分隔线（模型 / 思考档 / 标题）保持两翼细线形态。
- 代码块：`--code` 底 + radius md + 顶部语言标签与复制键（hover 显现）。
- 流式：光标 1.05em 细线呼吸、贴底 sticky、回看不被拽底（V37/V38 口径保留，视觉微调）。
- 回到底部（V47/V49）：消息列离底时在视口底部中央浮出 32px 圆形下箭头（`--elevated` + `--border` + `--shadow-pop`，floating 层 `z-10`），点击瞬时读底并恢复贴底跟随。**释放跟随的唯一判据 = 用户把位置往上挪了（scrollTop 净位移 > 8px、可累加）且确实离底 ≥ 80px**——按「距底距离」判会把视口变矮（输入框长高 / 查找条 / 缩放）误判成「用户滚开了」；按钮与释放状态同源，恢复跟随 / 切会话即收起。
- 轮次定位轨（2026-10-21，§4.12）：消息列右缘一条**每轮提问一道刻度**的竖轨，当前读到的那一轮最长最亮；悬停出预览、点击跳到那一轮。刻度是 `scroller` 的**兄弟**（与回底按钮同一挂载口径，不随内容滚走）。

### 4.5 滚动（血泪规则，不许回归）

- 消息列 `.thread-scroll`：`overflow-y: auto` + `overscroll-behavior: contain`——跟随滚动 / 回看 / 加载更早全靠它；**全 app 不显示滚动条**（`::-webkit-scrollbar { display:none }` + `scrollbar-width: none`）。
- 窗口与 `#root` 锁死（`overflow: clip`），滚动只发生在列内。
- 消息列上的浮动控件（回底按钮）挂 `scroller` 的**兄弟位**（relative 外壳 + absolute 定位于外壳底边），不许挂进滚动内容里——挂进去就跟着内容滚走。

### 4.7 浮层（菜单 / 弹窗 / 弹层）

- 菜单：`--elevated` + `--shadow-pop` + radius lg + `--border`；行钮高 28px 档；快捷键右对齐 `--faint`。
- **卡内浮层（输入卡底部的统计条 / 工具行）的包含块 = 整条容器**：`relative` 挂在**条根**上，各按钮包装器**不许**自带 `relative`（一旦定位就成了包含块，实测锚定也失去基准）；浮层 `absolute right-0 bottom-full … max-w-full`（宽度不超过整条）。**水平位置锚到被点的项**（2026-10-16，`lib/usePopoverAnchor`）：实测按钮中心让浮层居中，再夹在 `[0, 条宽 − 浮层宽]` 内——只写 style 不走 state（同 `streamCaret` 口径），无布局环境（jsdom）一个字不写、退回 CSS 的 `right-0`。理由（用户实测的两条并存）：① 窄窗口下统计条会 `flex-wrap` 换行、用量项落到行首，**相对按钮**的 `left-0 w-96` 浮层会向左溢出输入卡，被中列的 `overflow-hidden` 裁掉——浮层左半截看不见；② **贴条根右缘**展开的浮层又与靠左的项（会话统计 / Token 用量）隔得很远（点靠左的项、浮层却贴在卡片最右侧）。两者兼顾只剩实测锚定一条路。
- 模态：`--shadow-dialog` + 遮罩（约 40% 黑）；Esc 最上层关闭、Tab 圈定、焦点恢复（`useDropdown` 口径）。**长列表弹窗不许整体滚**（`DialogShell` 传 `bodyScroll={false}`，内容区转 `flex flex-col`）：过滤框 / 计数行 / 底部动作条固定，**只有清单滚**（`flex-1 min-h-0 overflow-y-auto`）——几十个模型滚下去，过滤框跟着滚出视野就没法接着筛（2026-10-19 用户口径；`ProviderModelsDialog` 与 `CustomProviderModelsDialog` 的候选视图已按此改）。

### 4.10 卡底统计条（2026-10-16，DeepSeek Harness 形态；2026-10-20 移到卡片外部）

  4. **供应商用量**（`Gauge` 图标）：**只有图标**（2026-10-16 修订用户口径——读数 / 窗口名 / 「+N」都不上条），到 warn / danger 档图标换色；完整读数在悬停提示（`title` / `aria-label`，读屏同源）与浮层里：浮层 = 全部供应商的全部窗口（读数 + 重置倒计时 + 更新时间）原样。条上不再有数字，**颜色是这一项唯一的档位信号**——故图标始终可辨（只有「一次都没拿到数据且最近一次查询失败」才整项置灰）。**浮层形态（2026-10-21 重做）**：头部 = 13px 「用量限额」+ 11px faint 更新时间 + 右端 28px 刷新键，其下内容区 `max-h-[min(60vh,26rem)]` 内滚；每个供应商一张 `--background` 卡片（`--border-soft` 描边、radius md、`px-2.5 py-2`），卡头 = 套餐名 / provider id（多账号才补账号标识）。窗口行分两档：**有比例的两行**——第一行名称 + 重置倒计时，第二行**通栏进度条 + 右对齐百分比**（条不再被固定宽度的名称与倒计时夹成一小截，也消掉百分比与倒计时之间的大段空白）；**纯余额一行**——名称在左、金额贴右，不画空条。进度条 6px 圆角、底槽 `--foreground/10`，实心段 <80% accent / ≥80% warn / 用尽 danger；百分比在 warn / danger 时同色（数字仍在，颜色不作唯一信号）。「无用量数据」与「补充探针失败（查询失败）」各占一块，不混排；commandcode 的**月度**窗口由后端补充探针补成进度条（omp 18.12 只报 5 小时 / 每周 / 余额）。

### 4.11 目标条（2026-10-20，DeepSeek Harness composer goal dock 形态）
- **位置**：输入卡**上方、卡片外部**，与卡片同宽同左缘（`--measure-content`、`mb-1.5`）；**只在当前会话已有目标时出现**——创建 / 编辑期间不占这条（由主输入框承接）。
- **常驻形态**（36px，`h-9`）：中性浮起条而不是强调色横幅——`--elevated` 底、`--border-soft` 描边、`--shadow-pop`、radius md（8px）；左 = `Target` 14px `faint` + 「目标」13px medium + 状态 11px `faint`（进行中 / 已暂停）+ 目标文本 13px `muted` 单行截断（完整文本在 `title` 里），右 = 三枚 **28px 圆形图标键**（暂停/继续、编辑、清除；14px 图标、hover 才给 `--hover` 圆底，清除键 hover 转 `--danger`）；用时 ≥1 分钟才以 11px `faint` 挂在动作键左侧。**状态不靠颜色区分**（暂停只换状态词与暂停/继续图标），与 Codex / ZCode 的目标行同一克制度。
- **创建 / 编辑 = 主输入框目标模式**（2026-10-20 用户口径）：点工具行「目标」按钮或目标条的编辑键 → 主输入框进入目标输入模式（`placeholder` 改成「描述目标；发送即设置」、目标按钮 accent；草稿为空且已有目标时预填目标，方便直接改），发送 = `goalCommand(create)` + **同一段文本作为启动消息发出**（goal 不会自己开跑；不发就只剩目标条、没有流式输出；运行中只设目标），成功后清空草稿、退出模式、**目标条出现并开始流式输出**。草稿里粘的图片**随启动消息一起发**（目标本身只是状态、不收附件）；只有图片没写目标时给提示，不静默发送；运行中图片留在输入框。**不**在条内展开编辑框、**不**弹窗；再点目标按钮取消输入模式。

### 4.12 轮次定位轨（2026-10-21，DeepSeek Harness `TurnNavigator` 形态）

- **位置**：消息列**右缘**（`Thread` 相对外壳内、`scroller` 的兄弟位，`right-3` = 12px），**垂直居中于正文可视带**：定位带 `top: 24px`、`bottom: 任务清单浮卡高 + 24px`，轨 `top: 50%` + `-translate-y-1/2`，`max-height: min(420px, 100%)`——浮卡展开时轨整体上移、不与卡片抢同一段右缘。宽度 **28px**（可点区域），轨道本体不画底、不加框。floating 层 `z-10`。
- **出现门槛**：会话里**至少 2 轮**（一轮没有「跳」的意义）；容器宽 **< 900px 收起**（`Thread` 外壳挂 `@container/thread`，轨道 `hidden @min-[900px]/thread:block`）——窄窗里正文两侧没有可站的位置，预览卡片也放不下。手机 PWA 沿用同一条规则（窄屏自然不出现）。
- **刻度**：**一轮 = 一道短横杠**，一节距 **10px 固定**（不按内容比例压缩；轮次多了在轨内滚动，两端各有一道 24px 遮罩淡出，只有那一端真的还有内容时才挂）。杠 **20×2px、右对齐、radius 2px、`transform-origin: right`**，四档状态：
  - **默认** = `--border` + `scaleX(.6)`（12px 视觉长）；
  - **悬停 / 键盘焦点** = `--muted` + `scaleX(.9)`；
  - **当前轮** = `--foreground` + `scaleX(1)`（20px 全长）+ `aria-current="true"`；
  - **未加载**（更早的历史页还没展开）= `--border` + `scaleX(.4)` + `opacity .6`，悬停即回到可点档（它不是禁用，是还没铺到）；
  - transition 只动 `scale` 与 `background-color`（150ms），不动布局。
- **当前轮的口径**：**贴底（< 80px，与 Thread 跟随同一常数 `lib/threadScroll.ts`）= 最新一轮**；否则阅读线 = 视口顶部往下 `min(96px, 20% 视口高)`，取最后一个行顶不超过阅读线的已加载轮次（`lib/turnRail.ts` 纯函数；DOM 锚点 = 用户行的 `data-turn`）。轨道自动把当前刻度带进可视范围，**指针在轨上时不抢**（用户正在挑，别把手底下的轨道挪走）。
- **预览**：悬停 / 聚焦刻度 → 轨左侧 10px 处浮出 **300px 卡**（`--elevated` + `--border-soft` + `--shadow-pop`，radius lg，`px-3 py-2.5`；`role="tooltip"`、`pointer-events-none`、淡入 120ms + `top` 过渡 140ms，减少动效时都关掉）：第一行 **本轮提问**（13px medium、单行截断），下面 **本轮最后一条已完成的助手正文**（12px `faint`、最多 3 行；没有正文就只有提问行；空提问回退「第 N 轮」）。卡片**按刻度中心垂直对齐、不做纵向夹取**——提示卡本来就比短轨高，夹进轨高会把它从被悬停的那一道上挪开；它是浮层，越过轨边不挡正文。
- **点击**：**已加载** → 锚点行顶落到视口顶部下方 **24px**（`turnJumpTop` 夹住滚动范围），平滑滚动，`prefers-reduced-motion` 时瞬时；**未加载** → 先把渲染窗口放大到刚好含这一轮（`growThreadLimit`，同一份本地消息流同步展开），下一帧锚点进 DOM 后**瞬时**落地（整页旧内容刚插到上方，平滑滚动会穿过与被点轮次无关的内容）。两条路都**先撤掉贴底跟随**（跳轮 = 读者接管，途中到达的流式增量不许把视口拽回底部）。
- **可达性**：整条轨是 `<nav aria-label="轮次导航">`，刻度是真 `<button>`（10px 高的可点行、28px 宽），`aria-label` = 「跳转到第 N 轮」/「加载并跳转到第 N 轮」。**键盘焦点框只描杠所在的 20×10 区域**（1px accent，`index.css` 的 `.turn-rail-mark:focus-visible` 关掉全局 28px 按钮环）——大框比「当前轮」那道杠还抢眼，焦点与当前轮就分不清了。**颜色不作唯一信号**：长度 + `aria-current` 并行表达「当前 / 未加载」。
- **实现**：数据面 `lib/turnRail.ts`（序号 / 预览 / 已加载 / 阅读线 / 落点，纯函数可单测）；组件 `thread/TurnRail.tsx`；`Thread` 只负责给完整消息流、渲染窗口起点 `hidden`、容器与跳转落点。**不许**把它做成第二套滚动条（不改 `scrollTop` 以外的滚动语义、不画滑块、不接管滚轮方向）。

## 5. 层级（z-index 命名层）

| 层 | 用途 | 参考值 |
|---|---|---|
| ground | 背景装饰 / 被动结构 | 0 |
| panel | 常规面板 | 0–10 |
| floating | composer、浮动工具面 | 10 |
| drawer | 抽屉 / 侧栏浮层（窄窗） | 20 |
| popover | 菜单、下拉、顶部弹层 | 30 |
| overlay | 模态遮罩与全局预览（弹窗在遮罩内 z-10） | 40+ |

组件禁止裸写 `z-[99]` 一类值；新层先判断是否其实是 popover / drawer / overlay。

## 6. 走查清单（改 UI 前核对）

1. 颜色只取自 §2.1 token；accent 是否只用在该用的地方。
2. 行高 / 间距 / 圆角是否走语义档位；有没有新的魔数。
3. 悬浮 / 选中 / 焦点三态是否齐全（键盘可达，`focus-visible` 用 accent 环）。
4. 深浅两套皮肤下是否都成立（`dark:` 变体禁用，只走 token）。
5. 滚动容器是否符合 §4.5；浮层挂载层与 z 层级是否符合 §4.7 / §5。
6. `prefers-reduced-motion` 下动效是否收敛。

## 7. 禁项（对齐 Codex 合约）

- 不引新 UI 库；不偏离参考产品的密度与结构。
- 不做营销式落地页；不做嵌套卡片；不做纯装饰渐变 / 发光。
- 不裸写 `z-*`；不在组件里写死色值（终端 16 色走 `--term-*` token、由 `lib/termTheme.ts` 在运行时读给 xterm，其余一律用应用 token）。
- 不删 `.thread-scroll` / 滚动条隐藏 / `kbd` 字体这三条血泪规则。


## 8. 手机远程控制（0.3.0）

远程控制是**同一产品的窄入口**，不是第二套设计系统；颜色 / 字体 / 圆角 / 层级全部沿用 §2 / §5。

### 8.1 桌面设置 ›「远程控制」

- 行式排布（与 §4.1 设置页一致）：标题 + 说明 + 分隔线，不做嵌套卡片；二维码是唯一的白底块（扫码需要对比度，深浅皮肤都不改）。
- 状态只用文字 + 既有 `ok` / `warn` / `danger` token；连接数、设备名、地址用 `font-mono` 小字；危险动作（撤销）走 `ConfirmDialog`。
- 地址 / 二维码 / 设备是三个独立小节；安全说明常驻，不折叠。

### 8.2 手机 PWA（`src/mobile/`）

- **壳**：`100dvh`（iOS 用 `--mobile-vvh` 由 visualViewport 更新）+ `env(safe-area-inset-*)`；顶栏 44px 触控目标、底部输入卡贴安全区。
- **列表**：一行 = 状态点（`SessionStatusDot`）+ 标题 + 项目 / 时间 + 待审批徽标；行高 ≥44px，无 hover-only 操作。
- **消息**：复用 `Thread` / `AssistantText` / `ToolRow` / `PlanCard` / `ApprovalCard`；移动端只覆盖 `.thread-scroll` 内边距与最大宽，不改字号 / 行高 token。
- **输入卡**：纯文本 textarea（16px 防 iOS 自动放大）、图片缩略图、发送 / 转向 / 排队 / 停止；运行中才显示队列与转向；停止走底部 sheet 二次确认。
- **弹层**：列表 / 新建 / 设置使用底部 sheet（`z-40`，圆角 18px，`max-height: 88dvh`）；`ConfirmDialog`（`z-30`）不得与 sheet 同时打开（先关 sheet）。
- **可达性**：所有图标键带 `aria-label`，状态点带文字标签；长按复制保留（移动入口不挂全局右键菜单禁用）。
