# 0.2.0 聊天对标（Codex / ZCode 范式）

> 目标：聊天形态的**布局、样式、流式对话、聊天框**按 Codex Desktop / Zcode Desktop 范式重做。
> 对标依据：`benchmark-codex-desktop.md`、`benchmark-zcode-desktop.md`；视觉规范：`../design-system/MASTER.md`。
> 原则：数据层不动（runtime / 事件帧 / 合并管线 / 队列真值全部保留），只重做**呈现与交互**。两者在关键位置一致的范式视为强约定（输入卡内嵌选择器、底部工具行、摘要式工具行等）。

## 1. 布局：双栏 → 三栏

### 1.1 左栏（对齐 Codex 左栏 + ZCode 任务列表）

- 顶部长驻命令行：`新建会话`（主命令，视觉最重）/ `搜索` / `命令中心`（对齐 Codex 的 New chat / Search / Plugins 排布）；工作区标题行与版本 chip 保持现状。
- 会话树：项目分组（可折叠，组头 = 名称 + git 徽章 + 计数）→ 会话行（标题 + 右侧紧凑相对时间 + 运行状态标：running 转圈 / idle / 完成勾）；当前会话以中性填充高亮（现有口径）。
- 行级操作维持 hover 悬浮图标（V43 口径），不引右键菜单。
- ZCode 式能力候选（按需，不默认全上）：置顶、分组色标、视图切换（分组 / 时间线）。

### 1.2 中列（消息流）

- 顶部会话标题栏：标题居中 + 左侧 `···` 菜单 + 右侧图标组（右面板开关、上下文容量环、供应商用量）；高度按 MASTER.md 语义 token。
- 消息流宽度：`--measure-content`（收紧行宽，见 MASTER.md）居中；用户消息右泡、助手通栏。
- 底部 composer（见 §3）；空态见 §4。

### 1.3 右栏：上下文面板（新增）

可开关（宽屏停靠 / 窄屏浮层），分区块、无嵌套卡片：

| 区块 | 数据来源（现状） | 内容 |
|---|---|---|
| 变更（Changes） | `git_info` | 工作区 dirty 统计 `+X −Y`、分支、提交 / 推送按钮（接 `CommitTaskPanel`）、ahead / behind |
| 进度（Progress） | 评估：omp 计划 / todo 数据源 | 任务清单（✓ / ○ / 进行中），没有数据源前不渲染该区块 |
| 子代理（Subagents） | `subagentsBySession`（V41） | 运行中子代理列表 + 状态 + 取消；点击展开转录（复用 `SubAgentStrip` 的增量读取） |
| 来源（Sources） | 评估：文件引用 / 工具读取记录 | 本轮引用过的文件列表（可点击打开 / 注入引用） |

- 工具切换浮层（对齐 Codex）：图标 + 名称 + 快捷键的行钮列表，切换右栏内容。
- 与 `SubAgentStrip` 的关系：`SubAgentStrip` 收进右栏（或至少与其共用数据），不再以独立状态条重复出现。

## 2. 消息流表达（对齐 Codex 01/02/06 截图）

### 2.1 行形态

| 元素 | 范式 | 现有基础 |
|---|---|---|
| 用户消息 | 右侧灰底小气泡，窄宽、右对齐 | 现状近似，收窄并对齐气泡样式 |
| 助手正文 | 通栏、无气泡；Markdown（代码块带语言标签 + 复制键） | V38 分块渲染 + 平滑揭示保留 |
| 时长行 | `Worked for 5m 32s ›`（整轮），可展开 | `useElapsed` 已有走字，改造为整轮摘要行 |
| 命令批 | `Ran 3 commands` 折叠行 | 工具行分组新做 |
| 子代理 | `Created 1 agent` 行 | `subagent_lifecycle` 帧已有 |
| 编辑卡 | `Edited 2 files +26 −1` + `Undo` / `Review` + 文件行（路径 + `+N −M`） | `diffStat` + `DiffDialog` 已有，重排为卡 |
| 文档卡 | 文件名 + `Document · MD` + `Open in ▾` | 生成文件路径（`export_session_html` 等产物）可入流 |
| 运行指示 | 工具行转圈 + 命令摘要；流尾 `Thinking` 行 | V35/V46 指示行已有，样式对齐 |

- diff 统计用状态色（added / removed），accent 不用作装饰（MASTER.md §颜色）。
- 消息操作条（编辑 / fork / 复制）维持 hover 出现；划选浮条样式对齐（引用到输入框 / 旁问）。

### 2.2 流式行为

- 保持现有管线（rAF 合并缓冲 → 分块渲染 → 平滑揭示 → 光标覆盖测量），本版只做**观感对齐**：揭示节奏、光标形态（1.05em 细线）、思考块展开 / 折叠与走字、贴底 sticky 语义全部保留。
- 工具行从「大卡」改为**摘要式折叠行**（默认单行，点击展开完整参数 / 输出）——这是与现状差别最大的一项，展开态保留现有内容能力。

## 3. Composer（聊天框，对齐 Codex / ZCode 输入卡）

- **卡片形态**：大圆角、悬浮于底部；卡片即「输入卡」，内部分层：
  - 卡顶行（对齐 ZCode）：项目 + 分支选择器内嵌（由 `ContextBar` 收缩迁入；两者与「+」菜单同槽位）；
  - 输入区：自动增高、动态 placeholder（新会话 = 引导文案；跟进 = 「发送后续指令…」）；
  - 卡底工具行（对齐两者）：左 = `+`（附件 / 引用文件 / 图片）、**执行模式菜单**；右 = **模型 + 思考档合并展示**（`模型名 · 档位 ▾`）、发送键（idle 圆形 `↑`；running 变停止 `■`）。
- **执行模式菜单**：菜单项 = 图标 + 名称 + 说明 + 当前项勾选（对齐 ZCode 截图）；现有三档（always-ask / write / yolo）映射：
  - `每次确认（Ask before changes）` / `自动编辑（Edit automatically）` = write 语义变体评估 / `完全访问（Full access）`；
  - `Plan mode` 是否引入：评估 omp 是否有对应权限档，无则菜单只呈现三档（不造不可用项）。
- **队列 / 插话**：保留现语义（Enter 插话 / Tab 排队 / Esc 中断交还）；待发区样式对齐 Codex 的输入框上方预览（行 = 文本 + 撤回 / 编辑 / 提升）。
- **大段粘贴**：保留（>2000 字符转文件引用）。
- **快捷键补全**：⌘⇧P（引用）、↑↓ 历史、Shift+Tab 模式循环——全部保留。

## 4. 空态与新建流程（对齐 ZCode 新建任务）

- 无会话时：居中问候语（按时间变化）+ 输入卡 + （可选）模板卡（如「总结本周提交」——由壳侧 prompt 模板实现，评估）。
- 无项目 / 无工作区引导：保留现有 `ChatEmptyState` 分支，样式并入新视觉。
- 新会话 = 在输入卡里选项目（或直接以当前上下文开聊）。

## 5. 命令面（对齐 Codex 05 截图）

- **⌘K 命令中心**：会话搜索结果置于顶部（对齐 `Search chats`），条目 = 标题 + 项目名 + **编号快捷键**（`⌃1..⌃9` 直接切换最近会话）；动作清单保持。
- **⌘F 查找 / ⌘[ ⌘] 导航**：保留。
- 右面板切换快捷键（对齐 Codex 工具浮层）：`⌃⇧G` 等映射在右面板落地时定稿。

## 6. 视觉 token 落地

- 按 `../design-system/MASTER.md` 全量落地：颜色（accent 克制、diff 状态色、无纯黑）、字级（mono-forward、表格数字）、圆角、动效（color / opacity / transform，禁止动画尺寸）、命名层级（替换裸 `z-*`）。
- 逐屏走查：左栏 / 消息流 / composer / 右面板 / 浮层（命令中心、模型、引用、diff、更新弹窗）。

## 7. 验收

1. **并排对照**：主界面、运行中（工具流 + 子代理）、空态、设置外浮层四类截图与 Codex / ZCode 参考图并排核对（比例、行高、留白、控件密度）。
2. 流式全场景：长思考（指示行 300ms 延迟见面）、多工具连续调用（摘要行聚合）、编辑卡 diff 统计、中断后队列交还——键盘与视觉双走查。
3. 功能回归：v1 验收清单全项重跑（呈现重做不许回退行为）。
4. 生产构建下长会话（30+ 轮）滚动与流式性能核对。
