# 排期 3：设置重构

> **状态：已实施**（2026-10-14），随 0.1.0 发布。本文是落地口径的定格版；实现细节与逐项变更见 `CHANGELOG.md` 的 0.1.0 节。
> 未落地项：§3 的「卡片式单选」（横向卡片 + 选中描边）为备选控件，本期逐页场景中没有需要三选一的二 / 三态项，未引入；§2 表格里的「评估项」（外观 / 更新是否收拢进设置）按原文属评估项，维持现状不开展。
> **后续修订（2026-10-15，四稿）**：常用设置展示清单按「桌面壳里有没有可观测差异」重筛，117 → 80 项（§2 / §4.1 / §5 里的 117 是当时的规模）；判据、删除清单与沿革见 `src/lib/settingsList.ts` 头部与 `CHANGELOG.md` 的 `0.2.0` 节。本文其余口径不变。
> **后续修订（2026-10-19，页头口径）**： §2 的「每个条目的页头唯一刷新」与 §4.1 的「页头唯一刷新降为图标钮」按用户口径重做——**设置页的页头装饰（说明 / 计数 / 刷新钮）整行退场**：常用设置（连「全部展开 / 全部收起」）与模型 / omp 约束 / 记忆 / 技能 / 已归档都没有页头行，只有插件（体检 / 安装插件）与使用统计（范围切换）保留功能控件行——其中插件页的可见范围下拉与这两个入口**并成一行**（下拉在左、入口靠右，2026-10-19 用户口径）；重读时机 = 切走页签重挂 +（常用设置 / 记忆 / 技能 / 已归档 / omp 约束）窗口重新获得焦点的静默回读。口径见 `design-system/MASTER.md` §4.6。

> 目标：设置**功能全量保留**（七个页签的所有读写能力），**操作方式与展现形式重新设计**——从「页签 + 列表」改为「独立视图 + 分组导航 + 搜索 + 行式控件」。
> 设计母版：Codex 设置（04 截图 + 官方设置文档，见 `benchmark-codex-desktop.md` §2.5）；行式控件与描述文案参考 ZCode。
> 写入口径不变：omp 侧只经 `omp` CLI（`config` / `models.yml` 例外等既有约定全部沿用），本应用偏好不写 omp 配置。

## 1. 形态与入口

- **独立视图**（不再是「标签栏单例标签」——v1 后该概念已退场）：
  - 打开：左栏底部「设置」、`⌘,`（对齐 Codex）；关闭：顶部「返回聊天」、`⌘W`、左栏「设置」再点一次；
  - 覆盖主区显示（现状聊天形态即此形态，本版做视觉与导航重构）。
- 顶部条：`← 返回聊天` + 页面标题（当前分组）+（右侧）搜索快捷键提示。
- 窗口内导航：左导航（分组 + 条目标题）；**窄窗折叠为图标栏**（保留现有容器查询方案）。

## 2. 信息架构（映射现有七页签）

| 新分组 | 条目 | 来源（现状页签） |
|---|---|---|
| **通用** | 常用设置（omp config 117 项） | 常用设置 |
| **模型** | 供应商 / 我的模型 / 模型角色 / 失败转移 | 模型 |
| **扩展** | 插件 / 技能 | 插件、技能 |
| **数据** | 记忆 / 使用统计 / 已归档对话 | 记忆、使用统计、已归档对话 |
| 评估项（不默认开展） | 外观（皮肤 / 语言）、更新（应用 / omp）是否收拢进设置 | 左栏底栏 / 左栏顶栏 chip 现状保留 |

- 顶部 `搜索设置`：跨**当前应用已加载的分组**过滤（常用设置 117 项、模型名、插件 / 技能名、记忆、归档会话）；不引入后端全文索引，纯前端过滤。（2026-10-19 用户口径：顶部条的搜索钮去除，搜索入口只剩 `⌘F`。）
- 每个条目的「页头唯一刷新」（模型页现状）保留，但视觉降为图标钮；能自动到达即渲染的（目录 SWR 等）不额外加刷新。

## 3. 控件体系（重设计）

| 控件 | 样式 | 用途 |
|---|---|---|
| 设置行（基础行） | 左：名称 + 描述（次要色）；右：控件；整行 `min-h` 语义行高 | 行式设置（多数场景） |
| 开关行 | 行 + 右侧 Switch | 布尔项、插件启停、记忆等 |
| 下拉行 | 行 + 右侧 `EnumSelect`（宽度按最长选项，沿用现有口径） | 枚举项、供应商 / 角色选择 |
| 数字 / 文本行 | 行 + 右侧输入（失焦提交）；长文本展开编辑 | 数值、字符串配置 |
| JSON 行 | 行 + 「编辑」打开编码面板（本地先校验形状） | array / record 类配置 |
| 卡片式单选 | 横向卡片组（标题 + 描述，选中描边） | 与 Codex `Work mode` 同款；用于少量高频二 / 三态选择（如插件范围、提交语言入口等） |
| 区块标题 | 分组节小标题（大写字距或次要色，不放大字号） | 行分节（对齐 Codex `General` / `Permissions` 分节） |
| 搜索框 | 顶部单行，命中高亮 | 分组内 / 全局过滤 |

- 视觉全量对齐 `../design-system/MASTER.md`：无嵌套卡片、无页面级大标题排版、accent 只做选中 / 焦点。
- 危险操作（删工作区 / 删归档 / 移除项目）统一走 `ConfirmDialog`（现状保留）。

## 4. 逐页改造

### 4.1 常用设置（117 项）

- 结构：**分组节**（顺序照上游）+ 节内行式；行 = 名称 + 键名 · 类型（次要色）+ 状态标注（`仅 TUI 生效` / `-1 = 默认`）+ 右控件；
- 编辑交互：开关 / 枚举 / 数字**行内直接改**（写完回读现状保留）；文本 / JSON 点「编辑」展开或弹层；
- 搜索：键前缀 > 键子串 > 名称 > 描述（现有四档打分保留）；命中行高亮；
- 恢复默认：行级 hover 图标（保留），危险确认不弹（可逆）。

### 4.2 模型

- 供应商区块（已添加列表 + 添加弹窗）→ 行式卡片列表；我的模型 / 角色 / 转移链重排为行式；星标 / 展开编辑等现有交互保留；
- 页头唯一刷新降为图标钮（见 §2）。

### 4.3 插件 / 技能

- 两页共用「范围选择器」；清单行式（名称 + 版本 / 来源 + 描述 + 右侧启停 / 安装 / 卸载）；
- 可选特性进「详情」展开区（整组覆盖写口径不变）；体检 / 发现警告用行内提示条，不弹窗。

### 4.4 记忆 / 使用统计 / 已归档对话

- 记忆：只读行式列表（路径 + 时间 + 删除）；
- 使用统计：三张卡 + 热力图**视觉对齐** MASTER.md（版式保留，图表是内容不是装饰）；
- 已归档：行式列表 + 行操作（恢复 / 打开 / 删除），分组照现状（按项目）。

## 5. 验收

1. **功能不减**：七个页签全部能力逐项核对（对照 `v1-schedule.md` §4 的冒烟清单中的设置部分）；117 项常用设置全项可达、可写、可恢复默认。
2. **搜索**：常用设置四档打分、跨条目过滤、命中高亮。
3. **键盘**：`⌘,` 打开、`⌘W` 关闭、Tab 圈定、Esc 最上层收起（继承 `useDropdown` 口径）。
4. **窄窗**：图标导航档位切换正常；`EnumSelect` / 弹层挂载层（最上层模态）口径不回归。
5. 视觉走查：与 Codex 设置截图并排对照（导航密度、行高、分节、留白）。
