# 对标调研：Zcode Desktop

> 用途：v2「聊天对标」的输入卡 / 左栏任务管理 / 交互依据。与 `benchmark-codex-desktop.md` 互为参照（两者在当代范式的关键位置高度一致的部分，即为强约定）。
> 证据：ZCode 官方文档（`zcode.z.ai/docs`，v3.15.x 快照）、官方截图（新建任务、执行模式、思考档）、开源仓库 `zai-org/ZCode`（README）。整理日期：2026-10-14。

## 1. 产品概览

ZCode 是 Z.ai 的 Agentic Development Environment（ADE）：同一工作区的桌面应用、浏览器界面与终端 Agent。以**任务（Task）**为中心组织会话，围绕自研 ZCode Agent 深度适配 GLM 模型族。

## 2. 界面解剖

### 2.1 左栏任务管理（官方文档）

- **任务视图三档**（视图菜单切换）：
  - `Grouped`：自定义分组（7 色标记：灰 / 红 / 橙 / 黄 / 绿 / 蓝 / 紫）；
  - `Workspace`：按项目归属；
  - `Timeline`：按时间倒序浏览近期工作。
- **控件行**：排序（Created time / Updated time）、搜索（命令 / 会话 / 文件）、归档入口（保留窗口 3/7/14/30 天可配；命中行有两个操作：`Unarchive` / `Delete`）。
- **任务组操作**：新建组、色点选色、点标题重命名、右键 `Ungroup & Delete`（只删组，任务保留并移出）；拖拽（任务进组 / 组内排序 / 组排序）；右键 `Move to Group` / `Remove from Group` / `Move to top`；折叠 / 展开（单个 + 全部）。
- **Quick Actions**：搜索框展开常用操作（新建会话、打开文件夹、搜索文件、切换主题、MCP 服务器、终端开关等），右侧显示对应快捷键。

### 2.2 新建任务空态（截图）

- 居中问候语（按时间变化，如 `Noon break?`）；
- **大输入卡**（居中、加宽）：
  - 卡顶行：**项目选择**（`📁 项目名 ▾`）+ **分支选择**（`⎇ master ▾`）——两者内嵌在输入卡内；
  - 说明行 placeholder：`Ask ZCode anything, @ for files, folders, or whiteboards, / for commands or agents, $ for skills, # for related conversations`；
  - 卡底工具行：左 = `+`、**执行模式**（`✋ Ask before changes ▾`）；右 = **模型**（`GLM-5.3 ▾`）、**思考档**（`🧠 Max ▾`）、发送（圆形 `↑`）。
- 下方：可关闭的公告条 + **模板卡**（如 `Standup Git Summary` / `CI Failures & Flaky Test Report` / `Customize`——每卡 = 图标 + 标题 + 说明）。

### 2.3 输入区能力（官方文档）

- `+` 菜单 = 添加上传附件 / `@` 引用文件与文件夹 / `#` 引用历史会话 / `/` 调用命令（`$` 调用技能直接键入）。
- **大段粘贴自动转附件**：超过阈值的长文本折叠成单个附件条目，全文仍送达 Agent（不刷屏输入框）。
- **划选浮条**：选中回复 / 思考 / 代码块 / 工具结果中的片段 → 小工具条 `Add to current task`，把选中文本作为引用追加进输入框（流式中的回复也可选，文本冻结在点击瞬间；仅支持单行选择）。
- **执行模式四档**（`Shift+Tab` 在输入框聚焦时循环）：
  | 档位 | 行为 | 适用 |
  |---|---|---|
  | `Ask before changes` | 每次文件编辑或命令都要确认（默认） | 关键代码、生产配置 |
  | `Edit automatically` | 文件编辑自动应用，命令仍需确认 | 日常迭代 |
  | `Plan mode` | 先审代码出计划，确认后开始编辑 | 复杂多步任务 |
  | `Full access` | 减少打断、尽量连续执行 | 清晰低风险任务 |
  菜单形态（截图）：每项 = 图标 + 名称 + 说明，当前项右侧打勾。
- **思考档三档**（`Low` / `High` / `Max`，默认 `Max`），入口在模型名右侧的思考图标；换模型档位随模型支持变化。
- **无项目工作模式**：不选文件夹直接开聊（`Work outside a project`），会话固定在无项目模式、隐藏分支选择器。

### 2.4 右侧面板（官方文档）

- 多 tab 面板：内置浏览器 / **Side conversation**（`/side`、`/btw` 或 `+` 菜单打开；占用主会话历史作上下文、自身时间线独立；关闭即销毁）等。
- **文件树**（工作区卡片右侧的文件树图标切换）：搜索、`只显示已变更文件` 一键过滤、Git 状态徽章（added / modified / deleted / renamed，目录聚合）；单击预览、双击 / Enter 打开、**拖进聊天插入文件引用**、右键 `Open` / `Open With` / `Add to Chat` / `Copy Path` / `Reveal`。
- **Git Graph**：分支泳道 + 合并关系的只读提交历史（选中提交看标题 / hash / 作者 / 日期 / 父提交）。
- **Wiki**：为仓库生成架构导览（每个论断回链到源码）。

### 2.5 任务与消息交互（官方文档）

- **Fork**：悬停已完成的助手消息 → `Fork`，从该点起新任务（标题 `Fork of <原名>`，继承历史 / 模型 / 思考档 / 目标进度；原会话不受影响；只能从干净完成的消息分叉）。
- **编辑已发送消息**（Edit History）：就地修改指令重发。
- **Goal Mode**：为长任务设定可验证目标（目标管理 + 完成验证 + 状态恢复）。
- 归档 / 分组 / 置顶 / 拖拽齐全；自动归档（完成 + 无未读 + 无置顶 + 超过保留窗口）。

### 2.6 设置（官方文档截图）

- `Settings → General`：Memory 开关（带 token 用量说明与「对新会话生效」提示）等，**行式控件 + 描述文案**。
- `Settings → Browser`：内置浏览器开关（对新会话生效）。
- 项目指令两层：`~/.zcode/AGENTS.md`（用户级）→ 工作区 `AGENTS.md`（项目级，主来源）；不跨目录合并、不展开 `@import`。
- 项目记忆：Agent 自动积累（与手写 AGENTS.md 分治：版本化约定 vs 机器本地事实）。

## 3. 对本站的对齐清单（落地到 v2）

| 项 | ZCode 范式 | 本站现状 | v2 / v3 动作 |
|---|---|---|---|
| 左栏 | 任务三视图 + 分组色标 + 归档 | 会话树（项目分组）+ 归档 | v2：分组与归档行样式对齐（色标 / 折叠 / 行操作） |
| 空态 | 问候语 + 输入卡 + 模板卡 | 空态（V32 `ChatEmptyState`） | v2：重做为「问候 + 输入卡」范式；模板卡按需 |
| 输入卡 | 项目 / 分支内嵌卡顶 + 底工具行 | 项目 / 分支在 `ContextBar`（输入框上方） | v2：收敛进输入卡（与 Codex 同向） |
| 执行模式 | 四档 + Shift+Tab + 菜单（图标 + 说明 + 勾） | 三档（always-ask / write / yolo，Shift+Tab 循环已有） | v2：菜单视觉对齐；评估补 Plan 档 |
| 思考档 | 模型名旁独立入口 | `ThinkingPicker` 已有 | v2：与模型合并展示（Codex 同款） |
| 划选 | 浮条 `Add to current task` | 划选浮条已有（引用 / 旁问） | 已有能力，样式对齐 |
| 大段粘贴 | 自动转附件 | 已有（>2000 字符转文件引用） | 保持 |
| 右面板 | 文件树 / 浏览器 / 侧会话多 tab | 无 | v2：右面板收敛为「上下文面板」（与 Codex 环境面板合一） |
| 设置 | 行式控件 + 描述 | 七页签 | v3 全量重构（见 v3-schedule） |

**不适用项**：Bot Channel（飞书 / 微信）、Remote 手机端、Idle-time 任务、GLM 模型绑定——omp 语境不同，不引入。
