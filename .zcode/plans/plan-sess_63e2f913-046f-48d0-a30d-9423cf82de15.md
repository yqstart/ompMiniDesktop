# 模型页增强：失败转移链 + 角色思考档

## 一、上游事实（本机 omp 18.2.1 实测，全部已跑通）

**失败转移链** = `retry.fallbackChains`，record 类型，值形如 `{"<key>": ["<selector>", ...]}`（**有序**）：

- key 三态：**角色名**（`default`）/ **模型 selector**（`provider/model-id`，该模型活跃时生效、与角色无关）/ **供应商通配**（`provider/*` + id 前缀通配 `openrouter/google/*`）。
- 条目可带思考档后缀（`:low`/`:high`/`:max`/`:off`）；不带后缀则继承失败轮次的档位；`provider/*` 条目**总是**继承。
- 触发时机：限流 / 过载 / 5xx / 网络类错误。**上下文溢出不走这条**（走压缩），说明行要写清。
- 两个配套开关（当前值取自本机配置）：`retry.modelFallback`（默认 `true`，**为 false 时链完全不生效**）、`retry.fallbackRevertPolicy`（`cooldown-expiry` 默认 = 冷却结束回主模型 / `never` = 不回）。
- 写入方式已验证：`omp config set retry.fallbackChains '<JSON>'` 整表覆盖（与 `modelRoles` 同款，点路径不可用）；`modelFallback` 只接受 `true`/`false` 字面量（传 `yes` 会被静默归一为 true）；`fallbackRevertPolicy` 传非法值直接报错（`Invalid value: bogus. Valid values: cooldown-expiry, never`）。
- 本机已有配置：`opencode-go/muse-spark-1.3-contributor: [opencode-go/deepseek-v4.1-flash]`——实现后界面要能如实显示它。
- **展示链路已存在**：`retry_fallback_applied` / `retry_fallback_succeeded` 早已被渲染成会话分隔线（「已切换备用模型重试」），配置生效后用户在会话里立刻看得到，这部分不改。

**角色思考档**：角色值本来就支持 `provider/model:档位` 后缀（你现在配的 `opencode-go/deepseek-v4.1-flash:max` 就是），只是界面 pick 时只写裸 selector、把档位丢了。档位候选照 `thinkingLevelsOf(model.thinking)`（`off` 恒在）+ 一个「默认」（= 不写后缀，交给 omp 的 `defaultThinkingLevel`）。

## 二、后端（`src-tauri/src/providers.rs`，+3 命令，与 modelRoles 同款「读→改→写回→回读」）

| 命令 | 干什么 |
|---|---|
| `get_fallback_chains` | 读 `retry.fallbackChains` + `retry.modelFallback` + `retry.fallbackRevertPolicy` → `FallbackChainsInfo{chains, modelFallback, revertPolicy}` |
| `set_fallback_chain` | `key` + `fallbacks: Option<Vec<String>>`；`None`/空数组 = 删该键；整表写回后**回读** |
| `set_retry_options` | 写 `modelFallback`（只发 `true`/`false` 字面量）+ `revertPolicy`（只发两个合法值），回读 |

- `AppState` 加 `retry_edit: Mutex<()>` 串行化链的读改写（`commands/mod.rs`）；`main.rs` 的 `generate_handler!` 注册 3 个。
- 纯函数 + 单测（照现有 `providers.rs` 文末 `#[cfg(test)]` 风格）：`parse_chains`（坏 JSON / 非数组值 / 非字符串条目一律丢弃不 panic）、`apply_chain_edit`（设置 / 覆盖 / 删除；key 与条目校验：非空、无控制字符、拒绝空白）、`validate_chain_key`（三种形态都放行，脏值拒绝）。

## 三、前端

**契约层**：`src/shared/types.ts` 加 `FallbackChainsInfo`；`src/shared/ipc.ts` + `src/shared/api.ts` 各加 3 个；`scripts/e2e-ipc-selfcheck.mjs` 的 `COMMANDS` 加 3 个（否则 e2e:ipc 直接失败）。

**新纯函数模块** `src/lib/modelSelector.ts` + 单测：`splitSelector(sel) → {base, level}`（只在 `:` 后那段是 `THINKING_ORDER` 里的已知档时才拆，避免误伤 id 里的冒号）、`joinSelector(base, level)`、`withLevel(sel, level)`（`level = null` 即摘掉后缀）。

**字典** `src/lib/locale.ts`：约 25 键 × 2 语言（中英同键由现有守卫单测强制）。

**新组件** `src/components/settings/FallbackChains.tsx`（`FallbackChainsSection`），挂在 `ModelsPanel` 里「模型角色」**之后**、「常用模型」之前：

- 标题行（`DiagramTree` 图标 + 「失败转移」+「刷新」）→ 一行口径说明（何时触发、上下文溢出不算、`provider/*` 条目继承档位）。
- 开关行：`retry.modelFallback` 开关 +（启用时显示）回归策略两档选择（冷却结束回默认 / 不自动回归）。
- 链列表（每条两块）：上行 = 类型徽章（角色 / 模型 / 供应商通配）+ key + 「编辑 / 删除」；下行 = 有序转移目标芯片排（`→ a:high → b/*`）。
- 「编辑」**行内展开**（不做浮层——设置页是可滚动容器，浮层会被裁掉）：类型分段控件 + key 候选区（角色芯片 / 模型搜索列表 / 供应商芯片，已在用的 key 标出且不可重复选）+ 转移目标列表（每项 = 序号 + 模型名 + 可点的档位 chip + 上移 / 下移 / 删除）+「+ 添加目标」就地展开模型选择器。
- 「+ 添加转移链」走同一套展开区；每次原子操作立即写后端（回读真值覆盖界面），失败给内联错误条。

**`ModelsPanel.tsx` 的 `RoleRow`**：selector 展示拆成 `provider/model` + 档位 chip；新增档位按钮（仅当该模型支持思考时出现，目录查不到该模型时退化为全集候选），点开行内芯片排：`默认 | off | low | … | max`（按 `thinkingLevelsOf` 裁剪），点选即写回 `selector:档位`。

## 五、范围边界（不做，除非你要）

- `retry.usageAwareFallback` / `usageReservePct` / `usageReservePolicy`（配额感知预切换）、`retry.maxRetries` / `baseDelayMs` / `maxDelayMs` / `waitForUsageReset`（重试预算）——都在同一配置组但属于另一件事，这次不碰。
- id 前缀通配（`openrouter/google/*`）UI 里不做候选，只支持 `provider/*`；手写过的前缀通配照原样显示、不丢。
- 不加「当前生效的转移」实时指示（那是会话内的事，已有分隔线）。
