## 设置 ›「记忆」页签（映射 omp 项目记忆：查看 + 删除）

### 上游事实（本机 omp 18.2.1 实测，已确认）

- 记忆根目录 = `<agentDir>/memories/`；agentDir 解析后端已有现成实现（`PI_CODING_AGENT_DIR` > `omp config path` > `~/.omp/agent`）。
- 每个 cwd 一个目录，目录名 = `--` + 绝对路径去掉首斜杠、把 `/` `\` `:` 换成 `-` + `--`（实测落盘：`--Users-yanqi-Desktop-WorkSpace-mino--`、`--tmp--`）。**与 sessions 目录名不是同一套编码**，不能混用。
- 目录内全是 Markdown：`MEMORY.md`（长期记忆）/ `memory_summary.md`（注入 system prompt 的摘要）/ `raw_memories.md`（逐会话原始记忆）/ `rollout_summaries/*.md` / `skills/<name>/SKILL.md`（含 scripts）/ `learned.md`（autolearn 开启时）。
- omp **没有** `omp memory` CLI，记忆由 agent 工具与启动后台流水线写入；删除的唯一方式就是删文件/目录。本机现状：6 个项目目录、90 个文件、24K–176K。

### 范围

**做**：按项目列出记忆目录 → 查看文件内容（Markdown 预览）→ 删除单个文件 / 清空某项目全部记忆（均二次确认）。
**不做**（记为后续候选）：编辑与新增记忆（上游没有可映射的写入入口，记忆由 omp 自己生成）、`/memory enqueue` 触发生成、记忆内容的语义化展示。

### 后端：新模块 `src-tauri/src/memories.rs`（4 个命令）

| 命令 | 作用 |
|---|---|
| `list_memories` | 扫 `agentDir/memories/`，每组返回：编码目录名、解出的路径、显示名、文件清单（相对路径/大小/修改时间/kind） |
| `read_memory_file(dir, file)` | 读单文件正文（上限 1MB，超出截断并标记 `truncated`） |
| `delete_memory_file(dir, file)` | 删单个文件 |
| `delete_memory_project(dir)` | 清空该项目记忆（删整个记忆目录） |

关键实现点：
- **目录名解码**：编码不可逆（路径里的 `-` 与 `/` 同形），用 DFS 按 `-` 分段逐级拼真实目录、合并优先从 1 段起（`ESV-tracsys-web` 这类含连字符的目录能正确解出）；解不出（项目已删）则退回显示编码名。
- **显示名**：解出的路径与覆盖层项目做前缀匹配（复用 `owner_project`）→ 项目名；否则路径 basename。
- **安全边界**：`dir`/`file` 入参一律拒绝绝对路径与 `..`，canonicalize 后必须落在 memories 根内，否则报错（记忆目录名来自磁盘，按不可信输入处理）。
- **排序**：`MEMORY.md`/`memory_summary.md`/`learned.md`/`raw_memories.md` 固定置顶，其余按相对路径字典序。
- 纯函数（解码、枚举排序、路径校验）配单测；删除/读取在临时目录上做真实行为测试。
